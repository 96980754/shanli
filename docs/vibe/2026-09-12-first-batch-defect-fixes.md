修复 Milvus 动态表达式未统一转义、反馈无法修改、可转人工拒答缺少业务域兜底、LangGraph 消息去重全量加载的问题。

- [x] Milvus 字符串字面量转义
- [x] 反馈同一用户/消息可覆盖更新并保持唯一
- [x] 可转人工拒答统一补充业务域
- [x] LangGraph 去重只投影消息元数据 ID
- [ ] 历史版本进入普通 RAG（保持只查当前版）
- [ ] Dashboard 统计口径
- [ ] history API 分页

同键反馈不新增记录；特殊字符不破坏 Milvus 表达式；scope/knowledge 拒答可按关键词补域且 policy/off_topic 不误补；消息去重不加载完整消息关系。
