# 问答人数/次数统计与产品线明细导出

日期：2026-09-23
来源：甲方需求——需要有问答人数和问答次数，点问答次数可以查看问答明细，每个问答对应哪个产品线，支持导出以便做进一步分析。

## 需求与决策

| 决策点 | 结论 |
| --- | --- |
| 问答次数口径 | 一问一答 = 会话内每轮收尾的 AI 终答消息（与满意度分母 `_EVALUABLE_ANSWERS_WHERE` 同基准）且 content 非空；含拒答。空 content 的澄清轮 tool_result 收尾不算一答（实测当前库 165 条：99 answered + 47 拒答 + 19 无 disposition 老数据） |
| 问答人数口径 | 上述终答消息所属会话的 distinct uid |
| 产品线判定 | 查询时解析：已存 `knowledge_disposition.domain`（拒答由 LLM judge 判定）非 unknown 时直接采用；否则用 `classify_domain_by_keywords` 按问题文本匹配业务线关键词（设置页业务线配置实时生效，存量数据全覆盖）。不修改消息写入链路 |
| 明细承载 | 新页面 `QaRecordsView.vue`，路由 `/dashboard/qa-records`（挂在数据总览路由组下）；总览「问答次数」卡片点击跳转并携带当前时段。初版曾置于知识运营 Tab，甲方要求「问答明细放在数据总览」后移入数据总览 |
| 导出格式 | CSV（UTF-8 带 BOM，Excel 直接打开不乱码），按当前筛选条件全量导出 |

## 目标

1. `/api/dashboard/stats` 新增 `qa_count` / `qa_user_count`，随现有 start_date/end_date（北京日界）过滤
2. `GET /api/dashboard/qa-records`：分页明细，支持时段/产品线/关键词筛选，每行含问题、回答正文、产品线、回答类型、用户、agent、会话
3. `GET /api/dashboard/qa-records/export`：同筛选条件导出 CSV
4. 前端总览新增「问答次数」（可点击）「问答人数」两张卡片，时段联动
5. 新问答明细页：筛选 + 分页表格 + 导出按钮，落在数据总览（甲方指定）

## 补充：隐藏「累计会话」「总消息数」（甲方反馈，同日）

甲方过总览统计栏时指认 `累计会话`（`total_conversations`，含趋势行）与 `总消息数`（`total_messages`）两张卡不需要，直接移除。顶部统计栏由 9 张缩为 7 张：活跃对话 / 问答次数 / 问答人数 / 知识缺口率 / 用户数 / 总反馈数 / 满意度。

- 后端接口与 i18n 键保留（`/api/dashboard/stats` 照常返回这两个计数，`dash.totalConversations*` / `dash.totalMessages*` 可能被其它面板复用）
- 顺带清理本次删除产生的孤儿：`MessageCircle` / `Mail` / `TrendingUp` / `TrendingDown` 四个图标导入，以及 `.stat-card.primary`、`.stat-trend` 样式块

## 补充二：明细展示回答正文（甲方反馈，同日）

甲方看明细页后反馈「问答明细没有回答细节啊？看不到系统怎么回答的」——初版只列了问题、产品线、回答类型，看不到系统实际答了什么。

- 后端 `_load_qa_record_rows` 取 `Message.content` 作为 `answer`（终答条件已排除空正文，故该字段恒非空）；导出 CSV 在「问题」后插入「回答」列
- 前端表格加「回答」列（2 行截断，与「问题」同款）；点任意行打开 560px 抽屉，抽屉内 `a-descriptions` 显示元信息，问题与回答各占一块，`white-space: pre-wrap` 保留 markdown 换行
- 导出测试的行数断言由 `splitlines()` 改为 `csv.reader`——回答含换行，按行切会拆散记录
- 未做：检索命中的知识来源/引用未在明细中展示（甲方未要求，需要再议）

## 验收标准

1. 总览顶部显示问答次数/问答人数，随时段筛选联动，点问答次数跳转 `/dashboard/qa-records` 且初始时段一致
2. 明细每行能看到问题、回答正文与产品线（拒答沿用 LLM 判定域，正常回答按业务线关键词分类，未匹配为「未分类」）；点行可看完整问答
3. 明细支持按产品线、关键词、时段筛选并分页
4. 导出的 CSV 可被 Excel 直接打开，列含时间/用户/问题/回答/产品线/回答类型，与页面筛选同口径
