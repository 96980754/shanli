# 5. 认款电子流

## 参与角色

- 财务：负责将每日到款信息录入 OA「认款电子流」，并对存在差异的认款信息进行核实、确认或修改
- 销售运营：依据 OA「认款电子流」中的到款信息进行认款，认款需对应合同/订单
- 商务：泳道中存在该角色，但 OCR 文本未体现其具体职责 [存疑]
- 抄送：财务部负责人、运营负责人、销售运营

## 流程步骤

### 1. 财务录入到款信息

财务将每日到款信息录入 OA「认款电子流」。

### 2. 销售运营认款

销售运营根据 OA「认款电子流」中的到款信息进行认款。认款需对应合同/订单；若涉及多订单，需分开合同/订单认款。

### 3. 信息差异处理

如信息存在差异，通知财务进行核实、确认或修改。

### 4. 流程抄送

流程抄送财务部负责人、运营负责人、销售运营。

## 关键判断与分支

- 到款信息是否存在差异：
  - 是 → 通知财务核实、确认或修改
  - 否 → 正常完成认款（原文本未明确后续动作，此为流程上下文推断 [存疑]）
- 认款是否涉及多订单：
  - 是 → 需分开合同/订单认款
  - 否 → 按单一合同/订单对应认款
