# 实验局建设联络文流程

## 参与角色
- 运营负责
- 销售总经理
- 实验局/样机借（流程/泳道）
- 销售运营
- 行销
- 产品管理
- 交付
- 财务
- 董事长（董事长助理）

## 流程步骤

### 1. 发起申请
销售按照填写要求提交实验局建设申请，申请信息包括：项目报备编号、项目背景、申请建设实验局原因、转商用时间、预计价格等。同时通过线下邮件通知销售运营，抄送销售总监。

### 2. 销售运营审核申请信息
销售运营审核销售提交的申请信息，确认其完整性、准确性，并判断是否符合实验局建设要求。  
判断：不符合 → 返回修改[存疑]。

### 3. 行销确认需求与技术方案
行销确认需求，并准备技术方案。

### 4. 产品管理团队主导需求评估
产品管理团队主导开展需求评估工作，涵盖合理性、可行性、库存等多方面（不限于此）。  
判断：若为非标准化产品需求 → 组织相关人员召开需求评估。

### 5. 交付确认实施方案
交付确认实施方案的可行性，制定实施计划及施工成本核算。

### 6. 成本核算
针对实验局整体成本（交付成本、产品成本、资金占用成本等）、毛利率等进行初步核算，并说明资金占用情况。

### 7. 线下审核

### 8. 审批
根据销售提交的实验局建设申请内容，结合财务核算情况，进行审批。  
判断：通过 → 继续；不通过 → 返回[存疑]。

### 9. 董事长审批
董事长对实验局建设进行审批。  
判断：审批通过 → 转至“实验局/样机借用流程”；不通过 → 返回[存疑]。

### 10. 进入实验局/样机借用流程
转至“实验局/样机借用流程”执行发货、调仓。借用设备挂至申请人名下，由申请人跟进转商用、归还等。

## 关键判断与分支
- 销售运营审核：申请信息是否完整、准确、符合实验局建设要求？若否 → 返回修改[存疑]。
- 产品管理需求评估：是否为非标准化产品需求？若是 → 组织相关人员召开需求评估；若否 → 不组织[存疑]。
- 审批：是否通过？若否 → 返回[存疑]。
- 董事长审批：是否通过？若通过 → 转至“实验局/样机借用流程”；若不通过 → 返回[存疑]。
