## 关键判断与分支

- **“符合 / 不符合”判断**
  - 符合 → 继续后续审批/收货流程。
  - 不符合 → 转其他流程；OCR 中“-不符合”与“转其他流程”相邻，可能存在直接关联，也可能涉及“退仓”。

- **“销售总经理权限内 / 超权限”判断**
  - 销售总经理权限内 → 销售总经理审批通过/确认完成。
  - 超权限 → 转董事长审批。

- **审批不通过的处理**
  - OCR 未出现“同意/不同意”“通过/不通过”等明确字样，无法确认审批不通过时的具体分支；推测可能走“退仓”或“转其他流程”。
