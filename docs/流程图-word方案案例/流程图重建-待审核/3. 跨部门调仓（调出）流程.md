# 跨部门调仓（调出）流程

## 参与角色

- 销售运营
- 行销（OCR原文为“行销25版”，[存疑]：可能为“行销/营销”泳道，也可能与“2025版”版本标注粘连）
- 产品管理
- 交付
- 财务
- 销售总经理
- 董事长（OCR原文“202量事长”）
- 仓库（录单）
- 销售总监（说明文字中作为抄送对象）
- 销售 / 借用人（说明文字中承担提交申请、确认收货及后续管理）

## 流程步骤

### 1. 发起调仓申请

销售 / 销售运营收到线下邮件通知后发起流程。线下邮件通知销售运营并抄送销售总监；销售按照填写要求提交申请，提交调仓流程。销售运营根据“实验局建设联络文”中的申请内容提交调仓流程。申请信息包括调仓设备名称、数量、申请原因、借用类型等关键信息。OCR中的“实验局申请”作为该环节的申请/触发单据。

### 2. 确认申请内容

销售运营确认申请内容，核对实验局终端、账号需求、库存等信息；确认申请类型（调出/借用[存疑]）等内容。

### 3. 产品需求评估与确认

产品管理主导需求评估工作，涵盖合理性、可行性、库存等多个方面（不限于此）；产品需行销需求确认（“行销”为OCR原文，[存疑]：或为“进行需求确认”/“营销需求确认”）。

### 4. 判断是否需交付并确认交付事项

- 需交付 → 交付确认实施方案，制定实施计划及施工成本核算。
- 无需交付 → 按OCR原文所示进入“审批”环节。

### 5. 财务核算与风险控制

财务负责涉及产品的成本核算、风险控制等；为后续审批提供财务核算情况。

### 6. 销售总经理审批

销售总经理根据销售提交的申请内容，结合财务核算情况，进行审批。若超出销售总经理审批权限，则提交董事长审批；未超出权限则在审批通过后进入后续流程。

### 7. 董事长审批

董事长对超出销售总经理审批权限的申请进行审批；审批通过后进入仓库发货环节。

### 8. 仓库核对设备清单并发货

仓库核对设备清单是否一致；一致则按照审批的设备清单执行发货。不一致的去向未在OCR中明确，见“存疑点”。

### 9. 确认收货及后续管理

发货后跟进销售确认收货（借用人）；借用人及时确认收货，并负责调仓设备的管理及后续处理。

## 关键判断与分支

- **是否需交付**
  - 需交付 → 交付确认实施方案，制定实施计划及施工成本核算。
  - 无需交付 → 进入审批环节（OCR原文：无需交付→审批）。

- **是否超出销售总经理审批权限**
  - 超出 → 提交至董事长审批。
  - 未超出 → 销售总经理审批后进入仓库发货环节。

- **设备清单是否一致**
  - 一致 → 仓库按照审批的设备清单执行发货。
  - 不一致（OCR标注为“否”） → 流程去向未在OCR中明确，待结合原图确认。
